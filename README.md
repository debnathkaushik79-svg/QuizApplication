# 📝 Quiz Application

A desktop-based Quiz Application developed using Java Swing and MySQL.

## 📌 Project Overview

This application allows users to participate in a multiple-choice quiz through a graphical user interface. The application displays questions, accepts answers, calculates the final score, and stores user/score information in a MySQL database.

## 🚀 Features

- User-friendly graphical interface
- Multiple-choice questions
- Question navigation
- Automatic score calculation
- Result display
- MySQL database integration
- JDBC connectivity
- User and score management

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Git & GitHub
- VS Code
